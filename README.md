# Machine Learning CIE 2 – Activity 1
## Dataset Inspection, Cleaning and Preparation

### Student Project
This repository contains my submission for Machine Learning CIE 2 Activity 1, focused on dataset inspection, data cleaning and preprocessing.

### Dataset Information
- **Dataset:** Titanic Dataset
- **Source:** [Kaggle – Titanic Dataset](https://www.kaggle.com/competitions/titanic/data)
- **Original file:** `train.csv`
- **Target variable:** `Survived`

### Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

### Work Completed
1. Dataset loading and inspection.
2. Identification of numerical and categorical columns.
3. Statistical analysis and frequency counts.
4. Missing-value analysis and treatment.
5. Duplicate checking and data consistency.
6. Exploratory Data Analysis (EDA).
7. Data visualization using histograms and count plots.
8. Categorical encoding using One-Hot Encoding.
9. Numerical feature scaling using StandardScaler.
10. Exporting the prepared dataset into CSV format.

### Final Dataset
- Original dataset: 891 rows and 12 columns.
- Prepared dataset: 891 rows and 11 columns.
- Missing values: 0 after cleaning.

### Repository Files
- `ML_ACTIVITY_1.ipynb` – Complete Google Colab notebook with code and outputs.
- `titanic_prepared.csv` – Cleaned and preprocessed dataset.
- `README.md` – Project documentation.
